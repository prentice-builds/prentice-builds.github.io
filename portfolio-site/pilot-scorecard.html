Pilot scorecard

A tool can save time and still miss something important. This scorecard holds one pilot to a bar you set before it starts, so the result decides what happens next and the demo does not.

Fill in the bars first. Come back with the results when the pilot ends.

The pilot

One scorecard covers one tool doing one task. Testing two tools means two scorecards.

to see how a finished scorecard reads.

1. Did people use it

Add up everyone taking part, across the whole pilot. If six people each handled five change orders, the task came up thirty times.

2. Was it right

Have a person check a sample of what the tool produced. A result is one thing it produced. For a review tool that is one issue it flagged. For a drafting tool it is one draft. A result is right if the person checking would have signed off on it.

3. Did it save time

Time one typical task from start to finish. Checking and fixing what the tool produced counts as time spent.

4. Do people want to keep it

Ask everyone taking part one question. Does this make the work easier.

Also worth writing down

No bar on these. They help explain the result and put a value on it.

The verdict

    What came back

    Hours saved on the task, whole pilot
    What those hours are worth
    The same pace over a full year
    What the pilot cost
    Issues raised early enough to act on

    How to use it

    Set the bars before the pilot starts and do not move them afterward. The defaults are placeholders. The right bar depends on the consequence of an error, and a missed payment issue deserves a harder bar than an awkward sentence in a meeting summary.

    The verdict reads the four questions in order. Use comes first, because an unused tool has not been tested. Being right comes before saving time, because speed does not make up for a miss that matters. A pilot passes only when every bar is met.

    Meeting time is not on this card on purpose. One tool rarely moves it, and when meetings do shrink it is the whole set of tools doing it. Track that across the team by running the baseline again a few months in.

    Nothing you enter here is sent anywhere. It stays in your own browser until you download or copy it.
